# 📚 StudyFlow - Student Productivity Dashboard

StudyFlow is a student productivity dashboard built using HTML, CSS, and JavaScript.

It helps students manage daily tasks, track progress, maintain study streaks, use a Pomodoro timer, and save quick notes.

---

## 🚀 Features

### ✅ Task Management

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Search tasks
- Filter tasks
- Set task priorities
- Add task due dates
- Detect overdue tasks
- Automatically sort tasks by priority

### 📊 Productivity Tracking

- Total task counter
- Completed task counter
- Progress percentage
- Visual progress bar
- Study streak counter
- Completion celebration

### ⏱️ Pomodoro Timer

- 25-minute work session
- 5-minute break
- Start timer
- Pause timer
- Reset timer
- Automatic work/break switching

### 📝 Notes

- Quick notes section
- Notes saved using Local Storage

### 🌙 Dark Mode

- Light mode
- Dark mode
- Theme preference saved using Local Storage

### 💾 Data Persistence

Task data, notes, theme settings, and study streak information are stored using browser Local Storage.
